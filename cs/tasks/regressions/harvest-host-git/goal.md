Harvest must never run agent-controlled git configuration on the host (verification finding 33, P0). It commits a workspace through a host-owned bare repo beside it (`harvest-<workspace>.git`, created before the sandbox starts) with `--work-tree`, and never reads the workspace's `.git`. The check plants three attacks in a fixture workspace: a filter driver activated by `.gitattributes`, `gpg.program` with signing on, and a `.git` gitfile pointing at another repo. It asserts that no marker is written, the other repo is untouched, and the workspace's ordinary files are still committed. Host git gets an allowlisted environment, so no credentials reach it.
